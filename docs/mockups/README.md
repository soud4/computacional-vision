# Mockups de referencia

El diseño visual proviene del proyecto de Stitch **"Visión Contador Desktop App"**
(`projects/9686804560167404119`), con cinco pantallas:

| Archivo esperado | Pantalla de Stitch |
|---|---|
| `01-principal.png` | Visión Contador - Interfaz Principal |
| `02-preprocesamiento.png` | Visión Contador - Configuración Preprocesamiento |
| `03-arduino.png` | Visión Contador - Control Arduino |
| `04-variante-a-procesando.png` | Variante A — Estado Procesando |
| `05-variante-b-sin-arduino.png` | Variante B — Error Arduino Desconectado |

Los archivos de imagen **no están versionados**: Stitch los sirve tras una sesión de Google, así que
hay que exportarlos desde el navegador y dejarlos en esta carpeta. Sirven como referencia visual y
como material para el informe del curso.

El sistema de diseño sí está capturado aquí en [`DESIGN.md`](DESIGN.md), y sus tokens están
traducidos uno a uno a Qt en `src/vision_contador/ui/tema.py`.
